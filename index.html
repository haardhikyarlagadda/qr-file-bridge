Transfer a file between two phones using only screens and cameras. No network is used during the transfer.

  1. Both phones: open this page (needs HTTPS the first time).
  2. Phone with the file: tap SEND a file below.
  3. Other phone: tap RECEIVE a file below.
  4. Follow the instructions on each screen — then hold the phones facing each other, 15–25 cm apart, so each camera sees the other screen. The transfer runs by itself.
  1. Choose a file — up to 1 MB (documents, photos, keys, configs).
  2. Optional: set a passphrase to encrypt the file (AES-256). Tell it to the receiver out loud — they must type the same one. Leave empty for an unencrypted transfer.
  3. Keep the default density & speed unless transfers fail.
  4. Tap Start sending, then have the receiver scan the code that appears.
  1. If the sender set a passphrase, type exactly the same one below. If they didn't, leave it empty.
  2. Tap Start scanning — your camera opens.
  3. Point the camera at the QR code on the sender's screen.
  4. Once joined, hold the phones facing each other and don't move them until you see the green success screen. The file is verified before saving.
