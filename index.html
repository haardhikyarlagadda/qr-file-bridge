QR File Bridge

screen → light → camera. nothing else.

Move a file between any two devices using only a screen and a camera. The file is encrypted, cut into chunks, and played as an animated QR sequence. No network protocol is used at any point — both devices can be in airplane mode.

How the optical channel works
  1. Sender compresses the file, encrypts it with AES-256-GCM (key derived from your shared passphrase), and splits the ciphertext into chunks.
  2. Each chunk becomes one QR frame; frame 0 is a manifest with the filename, frame count, and a SHA-256 digest.
  3. The sender screen loops the frames as an animation; the receiver camera decodes them in any order.
  4. The receiver can show an ACK QR listing missing frames — the sender scans it and replays only those.
  5. Once complete, the receiver decrypts, verifies the SHA-256, and saves the file. A failed passphrase or a corrupted transfer saves nothing.
